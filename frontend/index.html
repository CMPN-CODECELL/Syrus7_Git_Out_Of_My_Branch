Black-Scholes-Merton Engine

Analytical

Evaluates theoretical option prices using cumulative standard normal distributions modified for continuous dividend yields.

d1 = [ln(S/K) + (r - q + 0.5 * σ²) * T] / [σ * √T] d2 = d1 - σ * √T Call Price = S * e^(-q*T) * N(d1) - K * e^(-r*T) * N(d2) Put Price = K * e^(-r*T) * N(-d2) - S * e^(-q*T) * N(-d1)
  • Calculates full sensitivity Greeks (Delta, Gamma, Vega, Theta, Rho)
  • Hastings approximation for cumulative standard normal density
  • Supports real-time client-side calculation parameters sweeps

Crank-Nicolson Solver

Numerical Grid

Solves the Black-Scholes partial differential equation over a discretized price-time grid, resolving boundaries backward in time.

∂V/∂t + 0.5*σ²*S²*∂²V/∂S² + r*S*∂V/∂S - r*V = 0 Tridiagonal Matrix Solver: - α_i * V_(i-1)^j + (1 + β_i) * V_i^j - γ_i * V_(i+1)^j = RHS^(j+1)
  • LU Decomposition pre-factorization using SciPy SuperLU
  • Stability checks adjusting time step density dynamically
  • Resolves European option fair values on arbitrary grid steps
